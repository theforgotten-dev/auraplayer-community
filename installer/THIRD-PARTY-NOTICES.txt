libmpv is dynamically loaded from the replaceable libmpv-2.dll beside Aura.
This package uses the LGPL variant of the Windows build published in the
mpv-player/mpv repository, not the GPL build used during initial development.
The binary includes FFmpeg and other native dependencies. The upstream release
describes this variant as LGPLv3. License texts and exact binary provenance are
included in this directory.

the included licenses, including reverse engineering needed to debug changes

Go dependency names, versions and license/copyright files are included in
go-modules.txt and the per-module subdirectories. These include Gio, Oto,
purego, Beep, go-mp3, nativeaudio, taglib and their dependencies.
