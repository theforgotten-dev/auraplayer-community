Escuchar radio online en Windows

Busca emisoras por estilo musical desde Aura Player Community. El reproductor permite elegir entre el directorio Radio Browser y el catálogo Icecast.

Cómo buscar y sintonizar una emisora

  1. Instala Aura Player Community para Windows y abre Configuración.
  2. En la pestaña Radios, selecciona Radio Browser o Icecast. Ajusta la fuente del directorio y guarda los cambios.
  3. Abre Descubrir y escribe un estilo o tema, por ejemplo jazz, rock o news.
  4. Pulsa Buscar radios y elige Sintonizar junto a una emisora.

Cada emisora reemplaza la radio anterior: solo se reproduce una estación en vivo a la vez. La disponibilidad del catálogo y de cada transmisión depende de sus proveedores.

Configurar Radio Browser o Icecast

En Configuración → Radios puedes cambiar la URL de la API o del catálogo, los estilos sugeridos, el número de resultados y la personalización según tus valoraciones. Radio Browser también permite filtrar por país y ocultar emisoras marcadas como caídas. El filtro de país no se aplica al catálogo Icecast.

La URL inicial de Radio Browser es https://de1.api.radio-browser.info. El catálogo Icecast utiliza https://dir.xiph.org/yp.xml. Puedes editar estas fuentes y conservarlas con Guardar.

Qué ocurre si Radio Browser devuelve HTTP 503

HTTP 503 indica que el servidor no puede atender la consulta en ese momento. Desde Community 0.1.2, una búsqueda hace como máximo tres intentos totales, incluida la petición inicial. Mantiene una espera progresiva y respeta Retry-After cuando el servidor la envía.

Se consulta primero la API principal y después los espejos configurados en su orden, sin duplicados. Si todos fallan, la aplicación muestra el error. Este mecanismo no garantiza disponibilidad cuando el servicio externo está caído.

Ver y actualizar los espejos disponibles

En Radios, la lista de espejos es visible y editable: una URL por línea. Actualizar espejos disponibles consulta el DNS oficial de all.api.radio-browser.info y muestra los nombres anunciados. Pulsa Guardar para conservar los cambios.

El 30 de octubre de 2026, la consulta verificada anunció un único nombre, de1.api.radio-browser.info. IPv4 e IPv6 del mismo servidor no cuentan como dos espejos. La aplicación admite hasta 64 espejos configurados, pero no inventa servidores para completar una cantidad.

Si falla el descubrimiento, se conserva la lista anterior. Que un servidor aparezca en DNS no prueba que responda por HTTP. Consulta los código de configuración de la API y sus espejos.

También puedes reproducir tu colección local

La radio necesita acceso a Internet. Para escuchar tus archivos o ver videos locales, consulta los formatos compatibles de audio y video. La descarga gratuita incluye el motor multimedia para Windows.
