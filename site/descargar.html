Descargar Aura Player Community para Windows

Reproduce tu música, tus videos y radio online con una aplicación libre para Windows. La versión 0.1.2 es gratuita y está disponible como instalador o ZIP portable.

Descargar instalador .exeDescargar ZIP portable

Windows 10 y 11 · x64 · Instalador de aproximadamente 53 MB · Versión preliminar sin firma digital.

Requisitos y alcance de esta versión

Esta descarga está preparada para Windows de 64 bits. Incluye el motor multimedia libmpv y sus avisos de licencia; no necesita descargar ese motor durante la instalación. No hay en esta página paquetes para macOS, Android ni Windows ARM64.

Las pruebas automáticas y la instalación aislada se verificaron en Windows. No se han fijado requisitos mínimos de memoria o procesador mediante una campaña de pruebas en distintos equipos.

Cómo instalar el reproductor

  1. Descarga Aura-Player-Community-Setup-0.1.2.exe desde el enlace oficial de GitHub Releases; no necesitas una cuenta de GitHub.
  2. Ejecuta el archivo y revisa el editor, la procedencia y la información que muestra Windows. El instalador aún no está firmado; consulta la política de firma de código.
  3. Elige las opciones del instalador y abre Aura Player Community. Puedes agregar tus archivos con el selector o arrastrarlos desde el Explorador de Windows.
  4. Añade audio o video a la cola y utiliza los controles para reproducir, pausar, cambiar de pista o buscar una posición.

Instalador o portable: qué elegir

El instalador configura la aplicación para el usuario actual y ofrece accesos directos y asociaciones de archivos. El ZIP portable permite extraer y ejecutar los archivos de la aplicación sin pasar por el instalador. Conserva aura-native.exe, libmpv-2.dll y las carpetas incluidas juntos.

La opción portable también guarda sus preferencias en el perfil del usuario de Windows; no implica que todos los ajustes permanezcan dentro de la carpeta extraída.

Comprobar la descarga y consultar las fuentes

La publicación de la versión 0.1.2 incluye sumas SHA-256, metadatos del build y fuentes del proyecto y sus dependencias Go. Compara el hash de tu archivo con el publicado:

Get-FileHash .\Aura-Player-Community-Setup-0.1.2.exe -Algorithm SHA256

Community se distribuye bajo GPL-3.0-only. Los componentes de terceros conservan sus licencias. La publicación detalla el alcance de las fuentes incluidas y la revisión pendiente de las dependencias nativas.

Después de instalar

Consulta los formatos de audio, video y subtítulos o aprende a buscar emisoras y configurar radio online. Para informar un fallo, indica tu versión de Windows y los pasos para reproducirlo en los Issues de Community.
